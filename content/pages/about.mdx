## Hey, I'm Justin!

I'm a Senior Data Engineer with a passion for building scalable systems and turning complex data into actionable insights. Originally from Michigan, I now call Mississippi home, where I work at Camgian helping organizations leverage the power of their data.

## My Journey

My path into software engineering wasn't traditional. I'm a self-taught programmer who fell in love with technology through curiosity and countless hours of building and breaking things. This hands-on approach has given me a unique perspective on problem-solving and a deep appreciation for understanding systems from the ground up.

## What I Do

I specialize in:

- **Data Engineering**: Designing and building scalable data pipelines that process millions of events
- **Distributed Systems**: Architecting reliable, fault-tolerant systems using technologies like Kafka and Kubernetes
- **Full-Stack Development**: Creating intuitive web applications with modern frameworks like React and Next.js
- **Cloud Infrastructure**: Building and managing infrastructure on AWS with a focus on automation and observability

## Tech Stack

My daily toolkit includes:

- **Languages**: Python, TypeScript, Go, SQL
- **Data**: Apache Kafka, PostgreSQL, Redis, Apache Spark
- **Web**: React, Next.js, Tailwind CSS
- **Infrastructure**: Docker, Kubernetes, AWS, Terraform
- **Tools**: Git, VS Code, GitHub Actions
